# Repository instructions

## Project context

- This is the [two-s-indie/macroquad](https://github.com/two-s-indie/macroquad) fork, maintained for bug fixes and the 2D game **Where's the Yokai?**.
- The main development branch of this fork is `game`. Use `game` as the default base for work in this repository.
- Related repositories are siblings: `../miniquad`, `../quad-snd`, and `../Where-s-the-Yokai`, under the [two-s-indie GitHub organization](https://github.com/two-s-indie).
- The game uses the Macroquad and Miniquad forks' `game` branches.

## Changelog maintenance

- Update `CHANGELOG.md` whenever making and committing changes in this fork, including code, dependencies, tests, and documentation. Include the changelog update in the same commit as the change.
- Describe the change and its user or maintenance impact under `Unreleased`. Keep dated historical entries intact; add commit references when available.
